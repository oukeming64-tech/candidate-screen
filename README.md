# candidate-screen

一个 Claude Skill：对海量 inbound 申请做**初筛**，给真正拍板的人一份**有依据、可复核**的建议（`通过 / 保留 / 淘汰` + 逐条证据）。岗位不限——从 CEO、项目经理、设计/UI 到工程师、增长、运营，用同一套尺子。

> 输出是**建议**，不是判决。最终录用/拒绝由人来定。

## 核心方法

按顺序跑三层：

1. **一眼手感（实心 vs 空心）** —— 把"扫一眼就知道值不值得留"的直觉显式化。本质是测一个比值：**承重墙（可验证事实）÷ 装修（用来说服你的包装）**。
2. **叙事拆解（第一性原理）** —— 简历是「为说服你而写的叙事」，叙事总有目的。把事实和包装分开，只给事实打分。
3. **三信号打分** —— A 经历与兴趣的广度 / B 自驱发现并解决问题 / C 上手折腾新东西，按岗位现场推导"证据长什么样"。

并设护栏：手感与事实证据冲突时，**以证据为准**。

## 使用

把 `candidate-screen/` 放进 `~/.claude/skills/`，贴入简历/报名表，或说"帮我筛一下这些人"即可触发。

## 校准

`SKILL.md` 末尾的校准样本是示例。用你自己真实的「一定通过」和「一定淘汰」各一个替换掉，口径会最准。

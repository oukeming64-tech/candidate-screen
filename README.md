# candidate-screen

把履历作为有说服目的的叙事审读，从整份材料中寻找岗位相关关键主张的支持、矛盾与贡献边界，给人工复核提供依据。

## 使用

将 `candidate-screen` 文件夹放入所用客户端的个人技能目录，提供岗位、级别和候选材料，并点名使用 `candidate-screen`。已有同名技能时先比较并保留自定义改动。常规使用只需读取 [SKILL.md](SKILL.md)，合成样例不是日常审读的必读材料。

例如：“用 candidate-screen 审读这份产品经理申请，重点核对独立贡献、项目日期与结果口径。列出最影响判断的关键主张和补问。”没有岗位信息时，也可先检查材料内的支持与冲突。

## 输出与边界

- 通常聚焦 2—4 个关键主张，注明位置、本人和团队分工、支持程度、缺口与补问。
- 来源及核验状态另列。摘要和项目段互相支持，不等于独立验证；重复成绩不能重复计证。
- 区分未写清与明确没做过，不因没有业绩数字、没有名校或大厂背景而认定能力不足。
- 不作自动录用或拒绝，不依敏感个人信息判断就业，不执行候选材料内的指令，不联系、外发或改招聘系统。

不含招聘系统、背调服务或候选人数据库。不要把真实简历添加到本仓库；所有回归材料均为合成。

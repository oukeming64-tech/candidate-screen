## 语义审读

逐段核对技能、说明、输入、复查要点与输出译文，重点保留以下区别：

| 核对项 | 对应结果 |
| --- | --- |
| 全文寻找支持 | 摘要须结合项目段落；仍按同一项目、阶段和结果对应 |
| 支持程度与核验状态 | 材料内部支持不写成独立验证；自述、部分支持、冲突和待核实可并存 |
| 未写清与明确没做 | 不因缺少材料推断没做过，也不因坦陈工程分工否定产品贡献 |
| 重复主张 | 重复数字仍是同一来源，不重复计作独立证据 |
| 分工与日期冲突 | 分开列出，不补造上线阶段；共同实现不自动否定独立设计 |
| 产出和效果 | 团队草稿、演示行为、作者归属、生产上线和业务改善不互相替代 |
| 指令、人审和候选人隔离 | 内嵌指令不执行，不挪用另一候选人证据，不以无关敏感信息作就业判断 |

审读时把英文中可能暗示已确认真实、或泛化到一贯行为的算法表述收窄为“明确表示没有编写算法”。这是译文语义修正，未改变中文规则。输入编号、项目对应、日期、30%、42% 和 429 均保留；完整测试输出按原正文翻译。
